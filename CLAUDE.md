# Denk-Raupe — правила для Claude

Бесплатное офлайн-приложение для Android (планшет и телефон) для детей 1–2 класса. Ребёнок сам решает короткие смешанные наборы заданий: счёт, узоры, логика, пространство, внимание, буквы и слова. Ответы становятся бусинами гусеницы; в конце набора ребёнок сравнивает гусеницу с близнецом, бусины которого спрятаны под листьями.

## Сначала прочитать

- `docs/TZ.md` — бриф. Он обязателен. Раздел «Решено» не пересматривать без явной просьбы автора.
- `docs/IDEEN.md` — идеи на после выпуска и всё, что автор добавляет по ходу.

## Жёсткие правила

1. Каждое задание создаёт генератор или оно берётся из проверенного набора. Код проверяет, что верный ответ ровно один по признакам, которые видит ребёнок. Не доверять «на глаз».
2. Проверка только в конце набора. Свой верный ответ ребёнку не показывается. Нет галочек, красного и зелёного, счёта «3 из 6».
3. Награды без давления: ничего не теряется, питомцы не болеют и не грустят, нет серий со сбросом, рейтингов и ограничения времени на ответ. Реальных денег нет вообще.
4. Названия чужих приложений, игр, издательств и брендов, а также сравнения с ними не используются нигде: ни в коде, ни в документах, ни на странице в магазине. Ссылаться можно только на собственные проекты автора (Lese-Raupe).
5. Шрифт — локальный Inter с `font-feature-settings: 'cv05' 1, 'cv11' 1`. Никогда не Inter из Google Fonts.
6. Офлайн, без рекламы, покупок, аккаунтов и сторонних SDK. Данные только на устройстве.
7. Детский интерфейс и задания на немецком. Родительская часть на немецком и украинском.
8. Голосовой озвучки слов нет. Звуки игры есть и выключаются в настройках.

## Стек

Как в Lese-Raupe: Vite + TypeScript без фреймворка, тесты на Vitest (вёрстка — Playwright внутри тестов), позже Capacitor для Android. Стиль бусин взят из Lese-Raupe; картинки (головы, листья, корзинка) — свои, в `src/bilder/`.

- `npm run dev` — разработка; `#/` — экран набора, `#/stil` — витрина дизайн-системы.
- `npm run build && npm run screenshots` — скриншоты телефона и планшета в `screenshots/` (не в репозитории).
- `npm run artefakt -- <файл.html>` — вся игра одним HTML-файлом (шрифты, картинки, код внутри) для пробы без установки.

## Как работаем

- С автором — по-русски, коротко и по делу.
- Одна задача за сессию: сначала план, после «ок» — код.
- Работа в отдельной ветке; в `main` — только с явного «ок» автора.
- Когда появится код: перед каждым коммитом `npm test` и `npm run build` зелёные.
- Новые идеи после заморозки функций — только в `docs/IDEEN.md`.
- Репозиторий не засорять: только то, что нужно для работы.
- Никогда не коммитить: ключи подписи (`*.jks`, `*.keystore`, `key.properties`), пароли, токены, личные данные автора и её семьи (имя ребёнка, адрес, телефон, личная почта). Если сомневаешься — спросить.
