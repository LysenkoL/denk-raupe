# Denk-Raupe

Бесплатное приложение для Android: короткие смешанные наборы заданий для детей 1–2 класса — счёт, узоры, логика, пространство, внимание, буквы и слова. Самопроверка в конце набора через гусеницу и её близнеца. Офлайн, без рекламы, покупок и аккаунтов.

Статус: концепт утверждён, разработка ещё не начата.
