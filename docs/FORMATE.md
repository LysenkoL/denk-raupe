# Denk-Raupe — форматы: описание и таблица

Nov 16, 2026

Документ для сессий-исполнителей. Он отвечает на три вопроса: что такое формат в коде, какие поля у него обязательны, и какой формат к какому навыку и движку относится. Содержание заданий — в `docs/TZ.md`, раздел «Каталог заданий»; порядок работ — в `docs/PLAN.md`.

## 1. Термины

| Слово | Значение |
| --- | --- |
| Формат | один вид задания из каталога (Zahlenmauer). В коде — один файл в `src/aufgaben/` |
| Вариант | тот же формат с другим параметром (Verliebte Zahlen — Zahlenhaus с суммой 10). Отдельного файла нет |
| Движок | общий способ действия ребёнка на экране (заполнить сетку, расставить по порядку). Делается один раз |
| Область | группа форматов, которую родитель включает и выключает. Областей семь |
| Навык | то, что формат тренирует. По навыку ведётся уровень ребёнка и считается разнообразие набора |
| Уровень | ступень сложности внутри формата, не меньше трёх |
| Задание | одно конкретное условие, созданное генератором из зерна |

## 3. Описание формата в коде

Сейчас описание формата лежит в `src/aufgaben/format.ts`. Задание A2 из плана приводит его к виду ниже. Имена немецкие, как в существующем коде.

```ts
export type Bereich = 'zahlen' | 'muster' | 'logik' | 'raum' | 'blick' | 'woerter' | 'welt';
export type Motor = 'bild' | 'auswahl' | 'raster' | 'reihe' | 'verbinden' | 'weg' | 'bauen' | 'blick';

/** Настройка родителя, которая приходит в генератор */
export interface Einstellung {
  zahlenraum: 10 | 20 | 100;
}

/** Как ребёнок отвечает */
export type Eingabe =
  | { art: 'zahl'; einstellig?: true }  // ввод числа: места Z и E, при диапазоне «до 100» ещё H; einstellig — одно место E, только если формат при любом задании отвечает однозначным числом
  | { art: 'wahl' }                     // выбрать одну бусину из вариантов
  | { art: 'bild'; mehrfach?: boolean } // нажать на объект в картинке (mehrfach: несколько)
  | { art: 'zeit' }                     // время на циферблате и цифрами
  | { art: 'geld'; maxCent: number }    // сумма в евро и центах
  | { art: 'raster' | 'reihe' | 'paare' | 'weg' | 'bau' }; // составной ответ движка

export interface Format<B> {
  // паспорт
  id: FormatId;
  nr: number;                 // номер в каталоге брифа
  version: number;            // растёт при любом изменении генератора
  bereich: Bereich;
  faehigkeit: string;         // код навыка из раздела 2, например 'Z3'
  motor: Motor;
  klasse: 1 | 2;              // с какого класса
  lesen: 0 | 1;               // 1: чтение — часть задания («только для читающих»)
  braucht: ('woerterbuch' | 'autorensatz' | 'bilder')[];
  druck: boolean;             // false: только экран
  auftrag: string;            // ключ постоянной фразы в src/i18n/kind.ts
  stufen: number;             // не меньше 3

  // задание
  erzeuge(z: Zufall, stufe: number, e: Einstellung): B;
  loesungen(b: B): Antwort[]; // решатель: все ответы, которые подходят по видимому
  eingabe(b: B): Eingabe;
  wahl?(b: B, z: Zufall): Antwort[];
  /** true только у № 9 и 10: засчитывается любая верная расстановка */
  mehrere?: boolean;

  // показ
  zeichne(b: B, o: { hilfe: 0 | 2 | 3; gewaehlt: Antwort | null; vorrechnen?: boolean }): string;
  schrittVerraet?(b: B): boolean;
  beispiele(z: Zufall): B[];  // 2–3 задания учебного примера, от простого к обычному
  druckBlock?(b: B): string;  // блок для листа A4; обязателен при druck: true
}
```

### Правила к полям

1. **Единственный ответ.** `loesungen` написан независимо от генератора и не читает его служебные поля. Задание выдаётся, только если решений ровно одно и среди вариантов оно встречается ровно один раз. Это уже делает `aufgabeAus`.
2. **Исключение `mehrere`.** У № 9 и 10 решений может быть несколько. Задание выдаётся, если решение есть хотя бы одно. При сравнении близнец показывает тот же верный ответ, что дал ребёнок.
3. **Закрытый список признаков.** Форматы на «лишнее», узоры и классификацию (№ 19–23, 26, 27, 65, 72, 100) объявляют в файле список признаков, по которым ребёнок может рассуждать. Решатель перебирает все признаки из списка. Тест для «лишнего»: целевой признак делит объекты как «все против одного», и ни один другой признак не выделяет так другой объект. Подробно — `docs/LOESER.md`.
4. **Числовой диапазон.** Генератор берёт границу из `Einstellung`, а не из своих констант. Если формат на данном уровне не зависит от диапазона, он его не читает.
5. **Поле ввода не подсказывает ответ.** Размер поля числа зависит только от способа ответа формата и диапазона родителя, а не от конкретного задания: в два места вводится любое число 0–99, место H есть только при «до 100». Иначе ребёнок по запрету ввода узнал бы, что его число неверно (жёсткое правило 7 брифа).
6. **Вес ответа.** Считается из `eingabe` и `wahl`: при выборе из k вариантов вероятность угадать 1/k, при вводе числа и составном ответе — 0. Отдельного поля нет.
7. **Рисунок не выдаёт ответ.** До проверки `zeichne` не показывает правильность: деталь не прилипает к верному месту, весы стоят ровно. Тест «рисунок не содержит решения» есть у каждого формата.
8. **Помощь.** `hilfe: 2` подсвечивает нужную часть и не оставляет видимым только верный вариант. `hilfe: 3` показывает один шаг. Если шаг раскрыл бы всё решение, `schrittVerraet` возвращает true, и шаг показывается на похожем задании. Похожее задание — тот же формат и уровень, другое зерно.
9. **Учебный пример.** `beispiele` возвращает 2–3 задания: первое решается одним очевидным действием, последнее — обычное задание первого уровня. Каждое проходит проверку единственности.
10. **Воспроизводимость.** Одно зерно и одна версия дают одно и то же задание. При любом изменении генератора `version` увеличивается; сохранённое задание хранит своё условие целиком и показывается как было.
11. **Ответ — значение.** Новые виды значений, которых ещё нет в `src/perlen/antwort.ts`:

| Вид | Для чего | Что на бусине |
| --- | --- | --- |
| `ausdruck` | «задача» в № 89, 92 | короткая запись 7 + 3 |
| `groesse` | величина с единицей в № 104 | 15 cm |
| `stelle` | ответ — место в картинке (№ 20, 95, 103): хранится номер места | то, что стоит на этом месте |

### Вид сохранённого задания

Задание хранится целиком: формат, версия, зерно, уровень, условие, варианты в показанном порядке. К нему — история: ответы при каждой проверке, наибольшая ступень помощи, итог (`gold`, `selbst`, `hilfe`, `zurueck`), число повторов той же ошибки, день. Подробно — задание A3 в плане.

## 4. Что сдаёт исполнитель формата

Формат готов, когда выполнено всё:

- [ ] файл формата с паспортом по разделу 3, строка в таблице раздела 6 совпадает с паспортом;
- [ ] не меньше трёх уровней; у каждого в комментарии сказано, что именно усложняется;
- [ ] тест: 10 000 заданий на каждый уровень и каждый числовой диапазон, у всех ровно одно решение;
- [ ] тест на граничные случаи формата (наименьшие и наибольшие числа, крайние клетки);
- [ ] тест «ошибка, которую решатель обязан ловить»: неоднозначное условие, собранное вручную, отбрасывается;
- [ ] тест: одно зерно даёт одно задание;
- [ ] тест: рисунок не содержит решения, пока оно не показано;
- [ ] учебный пример из 2–3 заданий понятен без текста;
- [ ] помощь ступеней 2 и 3 нарисована на самом рисунке задания;
- [ ] вёрстка проверена на ширине 360 px и на планшете в обеих ориентациях;
- [ ] постоянная фраза-инструкция добавлена в `kind.ts`; знаки условий взяты из общего набора знаков;
- [ ] родительские тексты на немецком и украинском: что тренирует, пример, как помочь, не подсказывая ответ;
- [ ] печатный блок или `druck: false`;
- [ ] формат добавлен в скрипт обхода экранов.

Авторские наборы и картинки проверяет автор вручную; исполнитель готовит список на проверку.

## 5. Движки

| Движок | Действие ребёнка | Ответ | В коде |
| --- | --- | --- | --- |
| Bild | рассмотреть картинку; инструменты: отметить посчитанное, повернуть образец | число, время, сумма или одна бусина из вариантов | есть |
| Auswahl | нажать на объект в картинке | место или объект | есть |
| Raster | выбрать клетку сетки и заполнить её | одна клетка — число; несколько клеток — сетка | одна пустая клетка работает на Bild; несколько клеток — нет |
| Reihe | расставить по порядку в слоты | порядок или следующий элемент | выбор следующего элемента работает на Bild; расстановка — нет |
| Verbinden | соединить пары | пары | нет |
| Weg | пройти маршрут, вести след пальцем | клетка, выход или число | нет |
| Bauen | двигать, поворачивать, класть детали | постройка | нет |
| Blick | посмотреть и вспомнить; показ по готовности, кнопка «показать ещё раз» | число или бусина из вариантов | нет |

Bild — основа всех движков; в брифе он не назван отдельно, потому что ввод числа там описан как общая часть. Общее для всех движков: отмена последнего действия, выбор «предмет, затем место» наравне с перетаскиванием, зоны нажатия по брифу.

## 6. Таблица форматов

Столбцы:

- **Навык** — код из раздела 2. Область — первая буква кода.

- **Кл.** — с какого класса.
- **Нужно** — С: словарь; А: авторский набор; К: картинки; чт: чтение — часть задания.
- **Печать** — да или экран.
- **Очередь** — 0: эталон, в работе; 1: первая очередь, 50 форматов; 2: вторая очередь; 3: кандидат на отсев.
