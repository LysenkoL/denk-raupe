### Уже соответствует брифу — не переделывать

- Ответ хранится как значение, бусина рисуется из него.
- Цвет цифры на бусине выбирается по контрасту, с каймой; между заливкой и ободком тёмное кольцо. Сам рисунок бусины меняется по `docs/STIL.md`.
- Генератор и независимый решатель; выдаётся только задание с одним решением; зерно и версия сохраняются.
- Сравнение: лист поднимается при совпадении, золотой — только при первой проверке, повтор без изменений не считается ошибкой, верный ответ не показывается.
- Лестница помощи из четырёх ступеней; ступени 3–4 после первой проверки; шаг, который раскрыл бы решение, показывается на похожем задании.
- Muster: узор виден не меньше двух раз, решатель отбрасывает неоднозначные ряды. Wer ist es?: каждое условие нужно.
- Набор сохраняется после каждого изменения и восстанавливается.
- Звуки и выключатель. Постоянные короткие фразы для ребёнка.
- Локальный Inter с `cv05` и `cv11`; тест на отсутствие внешних адресов.
- Вёрстка на четырёх размерах экрана; зоны нажатия 56 и 48 px.

## 2. Правила для исполнителя

1. Одна сессия — одно задание из раздела 4, по порядку. Сначала план, после «ок» автора — код.
2. Работа в ветке от `main`. Перед каждым коммитом `npm test` и `npm run build` зелёные. После «ок» автора ветка сразу вливается в `main` и пушится.
3. Бриф не меняется. Если задание противоречит брифу или в брифе нет ответа — остановиться и спросить автора. Новые идеи — только в `docs/IDEEN.md`.
4. Задание закрыто, когда выполнены все пункты «Готово, когда» и в разделе 4 поставлена отметка с датой.
5. Тексты для ребёнка — только в `src/i18n/kind.ts`, для родителей — в `de.json` и `uk.json` с одинаковыми ключами.
6. Названия чужих приложений, игр, издательств и брендов не используются нигде.
7. Данные ребёнка не теряются: при изменении формата хранения пишется перенос старых данных и тест на него.
