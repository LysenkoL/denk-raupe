# Идеи и задачи

Сюда попадает всё, что не входит в текущую версию: идеи автора, мысли по ходу разработки, предложения ревью «на потом». После заморозки функций новые идеи записываются только сюда.

Формат: `- [ ] идея — откуда (дата)`; сделанное отмечается `[x]` с датой.

## Каталог заданий

- [ ] Автор просматривает каталог в `docs/TZ.md` и может добавить новые форматы — до заморозки брифа они идут прямо в бриф.

## После выпуска 1.0

- [ ] Голосовая озвучка — только если найдётся легальный и по-настоящему хороший вариант.
- [ ] Ввод ответов с бумажного листа в приложение.
- [ ] Несколько детей на одном устройстве.
- [ ] Задания-открытия без единственного ответа («Finde drei Möglichkeiten»): без бусины правильности, код проверяет только условия — исследование (15.11.2026)
- [ ] Родителю показывать вид ошибки, а не только её наличие: 42 вместо 24, ошибка на десяток, на единицу — исследование (15.11.2026)
