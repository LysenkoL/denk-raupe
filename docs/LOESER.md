# Denk-Raupe — решатели: как доказывается единственный ответ

Nov 16, 2026

Документ для сессий-исполнителей. Жёсткое правило 1 брифа: у задания ровно один верный ответ по тому, что видит ребёнок, и это проверяет код. Здесь записано, как именно это делается в трудных форматах. Общий вид формата — в `docs/FORMATE.md`, раздел 3.

## 1. Общий порядок

1. **Генератор строит условие, решатель его не знает.** Решатель получает только то, что нарисовано, и не читает служебные поля генератора (задуманный ответ, длину повтора, имя правила).
2. **Решатель перебирает всё.** Он не ищет «задуманный» ответ, а находит все ответы, которые подходят к условию. Пространства маленькие, полный перебор всегда возможен.
3. **Задание выдаётся, только если ответ один.** Иначе генератор берёт следующее зерно.
4. **У каждого формата есть тест-ловушка.** Это собранное вручную неоднозначное условие; тест проверяет, что решатель находит в нём больше одного ответа.
5. **Прогон.** 10 000 заданий на каждый уровень, у всех ровно один ответ.

## 2. Was passt nicht? (№ 26, 65, 72)

### Общее правило

У формата есть закрытый список признаков. Каждый объект получает значение по каждому признаку.

- Признак **выделяет** объект, если у этого объекта одно значение, а у всех остальных — другое, одинаковое между собой.
- Решатель проходит все признаки списка и собирает объекты, которые выделены хотя бы одним признаком.
- Задание годится, если такой объект ровно один. Несколько признаков могут выделять один и тот же объект — это не мешает.

Разбиения «два и два» и «все разные» никого не выделяют.

### № 26, фигуры

Четыре фигуры, на старшем уровне пять. Фигуры рисуются без поворота.

| Признак | Значения | Вид |
| --- | --- | --- |
| Форма | круг, квадрат, треугольник, ромб, звезда | основной |
| Цвет | цвета фигур из палитры | основной |
| Размер | маленький, большой | основной |
| Заливка | залитая, контур | основной |
| Число углов | круг 0, треугольник 3, квадрат и ромб 4, звезда 5 | производный от формы |
| Есть углы | да, нет | производный от формы |

Генератор:

1. Выбирает целевой признак, общее значение и значение лишнего объекта.
2. Каждому другому основному признаку назначает распределение, которое никого не выделяет: у всех одинаково, два и два, все разные. Для пяти объектов — ещё три и два, два-два-один.
3. Считает производные признаки и запускает решатель.

| Уровень | Что меняется |
| --- | --- |
| 1 | четыре фигуры; различается только целевой признак |
| 2 | четыре фигуры; остальные признаки тоже различаются, но никого не выделяют |
| 3 | пять фигур, или целевой признак производный: квадрат, ромб, квадрат и круг — лишний круг, у него нет углов |

Тест-ловушка — пример из брифа: красный круг, синий круг, красный квадрат, красный круг. Цвет выделяет синий круг, форма выделяет квадрат. Решатель обязан найти два ответа.

Обратный пример, который решатель обязан принять: красный круг, синий круг, красный квадрат, красный треугольник. Цвет выделяет синий круг; форма и углы не выделяют никого, потому что отличаются сразу два объекта.

### № 65, картинки

Три картинки из одной смысловой группы и одна из далёкой. Признаки берутся из словаря (`docs/WOERTER.md`): смысловая группа и главный цвет картинки.

- Далёкие группы заданы таблицей пар, которую проверяет автор: животные и фрукты, животные и транспорт, еда и одежда. Близкие группы (животные домашние и лесные) в паре не даются.
- Главный цвет нужен, чтобы поймать случай: собака, медведь, цыплёнок и шоколад — группа выделяет шоколад, цвет выделяет жёлтого цыплёнка.

### № 72, слова

Пять слов из словаря. Признаки:

| Признак | Откуда | С какого уровня бывает целевым |
| --- | --- | --- |
| Большая или маленькая буква (часть речи) | словарь | 1 |
| Первая буква | слово | 2 |
| Последняя буква | слово | 2 |
| Число слогов | словарь | 2 |
| Число букв | слово | не бывает, только проверяется |
| Смысловая группа | словарь | не бывает, только проверяется |
| Артикль | словарь | 3 |
| Рифма | словарь, по звучанию | 3 |

Генератор подбирает четыре слова с общим значением целевого признака и одно с другим, затем запускает решатель по всем восьми признакам. Тест-ловушка: Hund, Katze, Maus, Tisch, Pferd — смысл выделяет Tisch, число слогов выделяет Katze.

## 3. Hochhäuser (№ 78)

Дома высотой 1, 2 и 3 этажа. Число у края — сколько крыш видно с этой стороны: высокий дом закрывает все более низкие за собой.

| Уровень | Поле | Что дано |
| --- | --- | --- |
| 1 | ряд из трёх домов | числа с двух сторон |
| 2 | сетка 3×3: в каждой строке и каждом столбце дома 1, 2, 3 | все двенадцать чисел по краям |
| 3 | сетка 3×3 | часть чисел убрана; может стоять один готовый дом |

Решатель:

- ряд — перебирает все 6 расстановок;
- сетка — перебирает все 12 расстановок, где в каждой строке и столбце дома разной высоты;
- оставляет расстановки, которые согласны со всеми числами и готовыми домами. Ответ один — задание годится.

Для уровня 3 генератор убирает числа по одному и после каждого шага снова запускает решатель; останавливается, когда следующее удаление дало бы второй ответ.

Тест-ловушка: ряд с числами 2 слева и 2 справа. Подходят две расстановки, 1-3-2 и 2-3-1. Такой ряд выдаётся только с одним готовым домом. Пары (3, 1), (1, 3), (2, 1) и (1, 2) дают по одной расстановке.

Чтобы задание решалось рассуждением, а не подбором: на уровне 2 среди чисел есть хотя бы одно 3 (дома стоят по росту) и одно 1 (первым стоит самый высокий).

## 4. Rucksack packen (№ 86)

Несколько вещей, у каждой вес; у рюкзака предел. Нужно выбрать вещи с наибольшим общим весом, не превышающим предел.

Решатель перебирает все подмножества вещей (не больше 64 при шести вещах), считает их вес, отбрасывает превышающие предел и находит наибольший. Задание годится, если наибольший вес набирает ровно одно подмножество.

Условия для генератора:

- веса всех вещей разные, иначе две одинаковые по весу вещи дают два ответа;
- веса и предел укладываются в числовой диапазон родителя;
- ответ — набор вещей, порядок не важен.

| Уровень | Вещей | Свойство лучшего набора |
| --- | --- | --- |
| 1 | 4 | две вещи заполняют рюкзак ровно |
| 2 | 5 | две или три вещи заполняют ровно; если брать вещи по порядку от самой тяжёлой, лучший набор не получается |
| 3 | 6 | ровно заполнить нельзя; лучший набор на 1 меньше предела |

Тест-ловушка: вещи 2, 3, 4, 5 и предел 7 — подходят и 2 + 5, и 3 + 4.

## 5. Purzelwort (№ 60)

Буквы слова перемешаны; из них должно складываться только одно слово.

Проверка идёт не по школьному словарю, а по большому списку словоформ немецкого языка: иначе не поймать пары вроде Mehl и Helm, Lager и Regal, Esel и lese, Ampel, Lampe и Palme, Nebel и Leben, Tor, rot и Ort.

1. Скрипт сборки берёт каждое слово школьного словаря, сортирует его буквы и ищет в большом списке все слова с тем же набором букв, без учёта большой буквы.
2. Если найдено только само слово, в словаре ставится пометка `purzel: true`.
3. Генератор берёт только слова с пометкой. Большой список в приложение не входит.

Нужен открытый список словоформ с подходящей лицензией; лицензию проверить до использования. Если такого списка нет, набор слов для № 60 становится авторским и проверяется вручную.

| Уровень | Длина слова | Плитки |
| --- | --- | --- |
| 1 | 3–4 буквы | как в слове: первая буква существительного большая |
| 2 | 4–5 букв | все буквы большие |
| 3 | 5–6 букв | все буквы большие |

Слова с ß на уровнях 2 и 3 не даются. Умлаут — одна плитка. Перемешанный порядок не совпадает с самим словом. Ответ сравнивается как слово, а не как плитки: две одинаковые буквы взаимозаменяемы.

## 6. Остальные форматы

Для форматов, где единственность не очевидна. Везде решатель перебирает указанное пространство и требует ровно один ответ.

| № | Формат | Что перебирает решатель | Тест-ловушка |
| --- | --- | --- | --- |
| 9, 10 | Zauberdreieck, Waage | все расстановки; годится, если есть хотя бы одна (`mehrere`) | условие без решения |
| 11 | Zahlenreihe | все правила класса: шаг +k, шаг −k, чередование двух шагов, удвоение; подходящие к показанным числам должны давать одно продолжение | 2, 4, 8 — удвоение даёт 16, растущий шаг даёт 14; поэтому чисел не меньше четырёх |
| 15 | Höher oder tiefer | все числа диапазона; каждое условие должно быть нужным | условие, без которого ответ тот же |
| 19, 23 | Muster, Perlenkette | все длины повтора | ряд, видимый меньше двух повторов |
| 20 | Fehler im Muster | все места и все замены одного элемента; ровно одна делает ряд узором | ряд, который чинится в двух местах |
| 21 | Bilder-Gitter | правила по строкам и по столбцам для каждого признака; все согласные правила дают одну клетку | сетка, где строки и столбцы дают разные клетки |
| 25 | Mini-Sudoku | все заполнения сетки | сетка с двумя заполнениями |
| 29 | Wer ist es? | всех кандидатов; каждое условие нужно | уже есть в коде |
| 30 | Wer ist am größten? | все порядки, согласные с подсказками; самый высокий один и тот же | подсказки, не связывающие двух кандидатов |
| 33 | Wege zählen | число путей считается по клеткам; правило хода показано | — |
| 34 | Hölzchen | все перекладывания одной спички; наибольшая цифра получается одним способом | — |
| 37, 80 | Würfelbau, Seitenansicht | высоту каждого столбика по рисунку | столбик, целиком спрятанный за другим |
| 52 | Lücke | все буквы на месте пропуска; по большому списку словоформ слово одно | Wind и Wand |
| 54 | Fehlerwort | ошибочное написание не должно быть другим словом | — |
| 63 | Wortschlange | все разбиения змейки на слова по большому списку | змейка с двумя разбиениями |
| 68 | Bild-Gleichungen | все натуральные значения в диапазоне | две картинки, о которых известна только сумма |
| 76 | Zehner-Paare | все способы разбить на пары; остаток один и тот же | — |
| 87 | Befehl reparieren | все замены отмеченной стрелки | две стрелки приводят в цель |
| 95 | Fehler in der Mauer | все замены одного кирпича; ровно одна делает стену верной | — |
| 100 | Sortier-Baum | путь предмета по дереву; условия на развилке исключают друг друга | развилка, где подходят оба условия |

Форматы, которых здесь нет, имеют один ответ по построению (счёт, вычисление, чтение шкалы). Решатель у них тоже отдельный от генератора, и прогон 10 000 заданий обязателен.
